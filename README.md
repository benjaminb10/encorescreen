# Encore Screen

Turn any device into an extra screen for your Mac, over Wi-Fi.

Encore Screen gives an old Mac (an iMac from 2012, a forgotten MacBook…) a second life as a wireless extended display for your main Mac.

## How it works

One app, installed on both Macs. On first launch it asks how you'll use this Mac:

- **This is my main Mac** (macOS 14+): a menu bar app that creates a virtual display, captures it with ScreenCaptureKit, encodes it as low-latency H.264 (VideoToolbox) and streams it over TCP. The pointer is sent separately over UDP and drawn on the screen side, so it feels instant.
- **Make this an extra screen** (macOS 10.15+, perfect for an older iMac or MacBook): advertises itself on the network (Bonjour `_encorescreen._tcp`), decodes the stream in hardware and shows it full screen.

Details:

- Screens are discovered automatically; Encore Screen reconnects to the last one.
- The virtual display matches the screen's resolution (HiDPI on Retina screens), and macOS remembers where you placed it.
- Only changed frames are sent, so a still screen costs almost nothing.
- AirDrop (`awdl0`) makes Wi-Fi hop channels several times per second, causing stutter. Encore Screen pauses it while streaming (a sudo rule limited to `ifconfig awdl0 up/down`, installed once from the onboarding).

## Build

```sh
./build.sh
```

Produces `build/Encore Screen.app` (universal, macOS 10.15+) and `build/EncoreScreen.dmg`.
With a Developer ID Application identity in the keychain, the app is signed with the hardened runtime, notarized and stapled.
Set `SIGN_ID` to a code signing identity to keep the Screen Recording permission across builds (falls back to ad-hoc signing).

Icons are generated by `swift Icons/mascots.swift Icons`.
