# SpareScreen

Turn any device into an extra screen for your Mac, over Wi-Fi.

SpareScreen gives an old Mac (an iMac from 2012, a forgotten MacBook…) a second life as a wireless extended display for your main Mac.

## How it works

| App | Runs on | Role |
|---|---|---|
| **SpareScreen** | Your main Mac (macOS 14+) | Menu bar app. Creates a virtual display, captures it with ScreenCaptureKit, encodes it as low-latency H.264 (VideoToolbox) and streams it over TCP. |
| **SpareScreen Receiver** | The spare device (macOS 10.15+) | Advertises itself on the network (Bonjour `_sparescreen._tcp`), decodes the stream in hardware and shows it full screen. |

- Receivers are discovered automatically; SpareScreen reconnects to the last one.
- The virtual display matches the receiver's resolution, and macOS remembers where you placed it.
- Only changed frames are sent, so a still screen costs almost nothing.
- AirDrop (`awdl0`) makes Wi-Fi hop channels several times per second, causing stutter. SpareScreen pauses it while streaming (a sudo rule limited to `ifconfig awdl0 up/down`, installed once from the onboarding).

## Build

```sh
./build.sh
```

Produces `build/SpareScreen.app` (universal, macOS 14+) and `build/SpareScreen Receiver.app` (universal, macOS 10.15+).
Set `SIGN_ID` to a code signing identity to keep the Screen Recording permission across builds (falls back to ad-hoc signing).

Icons are generated by `swift Icons/mascots.swift Icons`.
