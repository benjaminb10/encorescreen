# Encore Screen

Turn any device into an extra screen for your Mac, over Wi-Fi.

Encore Screen gives an old Mac (an iMac from 2012, a forgotten MacBook…) a second life as a wireless extended display for your main Mac.

## How it works

Encore Screen runs on your main Mac (macOS 14+, menu bar app). It creates a virtual display, captures it with
ScreenCaptureKit and encodes it as low-latency H.264 with VideoToolbox. The extra screen can be:

- **Any device with a browser** (phone, tablet, PC, Chromebook, older Mac with Chrome). Scan the QR code from the
  menu: nothing to install. The page decodes the video in hardware (WebCodecs) and supports touch control
  (tap, scroll, long press, pinch) and the device's keyboard when a text field is focused.
- **Another Mac with Encore Screen** (macOS 10.15+): choose "Make this an extra screen". Smoothest option,
  ideal for an older iMac or MacBook; it starts by itself at login and keeps the Mac awake.

Details:

- The pointer travels separately (UDP for Macs, WebSocket for browsers) and is drawn on the screen side, so it feels instant.
- Retina screens get a HiDPI virtual display; macOS remembers where you placed each screen.
- Security: browser links carry a random secret (renewable), and every new device must be allowed once on the main
  Mac. HTTPS/WSS is used when a certificate is installed (see `docs/https.md`).
- AirDrop (`awdl0`) makes Wi-Fi hop channels and causes stutter: Encore Screen pauses it only while things move on
  the extra screen (a sudo rule limited to `ifconfig awdl0 up/down`, installed once from the onboarding).

## Build

```sh
./build.sh
```

Produces `build/Encore Screen.app` (universal, macOS 10.15+) and `build/EncoreScreen.dmg`.
With a Developer ID Application identity in the keychain, the app is signed with the hardened runtime, notarized and stapled.
Set `SIGN_ID` to a code signing identity to keep the Screen Recording permission across builds (falls back to ad-hoc signing).

Icons are generated by `swift Icons/mascots.swift Icons`.
